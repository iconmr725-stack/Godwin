MUM FLORENCE v2

1. In your GitHub repository, delete the old zip (open it > trash icon > Commit), then
   Add file > Upload files > drag in MumFlorence-v2.zip (do not unzip) > Commit.
2. Actions tab: wait for the green tick (about 8 minutes). Releases > download app-debug.apk.
3. UNINSTALL the old Mum Florence from your phone first, then install the new one.
4. Open it and tap "Set up everything".
